This is a webpage I created a while back for an Information Visualization class at CU Boulder. 

![Info Visualization Webpage](/images/Info-Vis-Tableu-Screenshot.png)

[Open the interactive information visualization page](/assets/pages/info_visualization_project.html)

I used the "million song dataset" along with tableu to sift through data from the last 100 years of music, and create interactive visuals to teach users about the history of recorded music.

This project got me much more comfortable using tableu. I ended up creating a "bar chart race" animation showing sales data when I worked.
